 
# Healthcare Data Analytics and Decision Making

## Project Overview
This project analyses 2022 delivery data from Shoreline Birth Center using Microsoft Excel. The objective is to examine delivery patterns, compare Cesarean delivery rates with a national benchmark, and identify differences across patient groups.

## Project Objectives
- Analyse Cesarean and vaginal delivery rates.
- Examine delivery patterns across pregnancy risk categories.
- Explore delivery patterns across age groups.
- Examine maternal mortality statistics.
- Present findings to support healthcare decision-making.

## Tools and Technologies
- Microsoft Excel
- Pivot Tables
- Data Cleaning
- Data Analysis
- Data Visualization

## Key Findings
- Total deliveries: 8,379.
- Cesarean deliveries: 2,847 (33.98%).
- Vaginal deliveries: 5,532 (66.02%).
- National benchmark: 32.1%.
- High-risk Cesarean delivery rate: 82.91%.
- Low-risk Cesarean delivery rate: 22.40%.

## Methodology
The analysis involved organising and summarising delivery data using Microsoft Excel Pivot Tables. Delivery methods were compared across pregnancy risk categories and age groups.

## Recommendations
The findings highlight the importance of monitoring delivery patterns, reviewing clinical indications and improving healthcare data documentation.

## Limitations
The analysis is based on the available 2022 educational dataset. The findings describe observed patterns and do not establish causation.

## Data Source
EHRGo educational activity – Shoreline Birth Center, 2022.
